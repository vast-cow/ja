Windows Terminalをライトテーマ（白背景）に切り替えたとき、PowerShellの既定のシンタックスカラーが見づらくなることがあります。特にコマンドや数値、選択範囲の視認性が落ちやすいのが難点です。

この問題は、**PSReadLine**のカラースキームをカスタマイズすることで解決できます。表示色のコントラストを調整すれば、白背景でも読みやすいPowerShell環境を作ることができます。

---

## 最小構成のカスタマイズ例

以下は、シンプルかつ実用的な設定例です。

* 基本のテキストはターミナルの既定色に任せる
* 数値はやや暗めのグレー
* コマンドはアクセントカラー（黄色）
* 選択範囲は反転表示

```powershell
# PowerShellで実行（PSReadLineが必要）
Import-Module PSReadLine
Set-PSReadLineOption -Colors @{
    ContinuationPrompt = "$([char]0x1b)[39m"      # 既定の前景色
    Default            = "$([char]0x1b)[39m"      # 通常テキスト
    Type               = "$([char]0x1b)[39m"      # 型名
    Selection          = "$([char]0x1b)[39;49;7m" # 反転表示
    Command            = "$([char]0x1b)[33m"      # コマンド（黄色）
    Member             = "$([char]0x1b)[39m"      # メンバー名
    Number             = "$([char]0x1b)[38;5;242m"# グレー（256色）
}
```

---

## 設定のポイント

### ■ 既定の前景色 `[39m]`

テキストカラーを固定せず、Windows Terminal側の配色に任せます。
これにより、ライトテーマでもダークテーマでも自然に馴染みます。

### ■ コマンドは黄色 `[33m]`

白背景でもしっかり目立つ、標準的で視認性の高い色です。
強すぎず、長時間の作業でも疲れにくいのが利点です。

### ■ 数値はグレー `[38;5;242m]`

256色パレットを使った落ち着いたグレー。
主張しすぎず、それでいて読みやすさは維持されます。

### ■ 選択範囲は反転 `[7m]`

前景色と背景色を入れ替えることで、テーマに関係なく確実に目立ちます。

---

## 設定を永続化する方法

毎回設定するのは面倒なので、PowerShellのプロファイルに保存しておきます。

1. プロファイルを開く

   ```powershell
   notepad $PROFILE
   ```

2. 上記の `Set-PSReadLineOption` のコードを貼り付けて保存

3. ターミナルを再起動（またはその場で再実行）

---

## まとめ

PSReadLineの配色を少し調整するだけで、白背景でも見やすいPowerShell環境が整います。
特に「既定色を活かす」「アクセントだけ加える」という方針にすると、テーマ変更にも柔軟に対応できます。

シンプルな設定ですが、日常の操作性は確実に向上するはずです。
