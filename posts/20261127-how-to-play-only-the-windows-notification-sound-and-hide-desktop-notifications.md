Windowsでは、通知音だけを鳴らして、デスクトップ右下のポップアップ（通知バナー）を非表示にすることができます。

## 1. Windows 11の設定方法

1. `Windowsキー + I` で「設定」を開く。
2. 「システム」→「通知」を開く。
3. 通知を変更したいアプリをクリックする。
4. 以下のように設定する。

| 設定項目 | 設定値 |
|---|---|
| 通知 | オン |
| 通知バナーを表示する | **オフ** |
| 通知センターに通知を表示する | オン |
| 通知が届いたら音を鳴らす | **オン** |

## 2. 設定後の動作

| 通知の種類 | 動作 |
|---|---|
| 通知音 | 鳴る |
| デスクトップのポップアップ | 表示されない |
| 通知センターへの記録 | 残る |

通知センターは `Windowsキー + N` で確認できる。

## 3. 注意点

- 「応答不可」はオフにする。オンにすると通知音も抑制される場合がある。
- すべてのアプリでこの動作にしたい場合は、原則としてアプリごとに設定する必要がある。
- アプリ独自の通知機能がある場合は、アプリ側の設定も確認する。

## 4. Windows 10の場合

「設定」→「システム」→「通知とアクション」から、対象のアプリを選択して同様に設定する。
