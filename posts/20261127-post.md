Windowsの右下に出るポップアップ通知（トースト通知）の位置は、Windows 10・11の標準設定では変更できません。

ただし、**Windhawkという無料のWindowsカスタマイズツール**を使えば、右上・左上・左下・画面中央などに移動できます。

## **設定手順**

1. [Windhawk公式サイト](https://windhawk.net/?utm_source=chatgpt.com) からダウンロードしてインストール。
2. Windhawkを起動して「Explore」を開く。
3. `Customize Windows notifications placement` を検索。
4. 「Details」→「Install」をクリック。
5. 「Settings」で通知の表示位置を変更。
6. 「Save settings」で保存。

## **表示位置の設定例**

| 表示位置   | Horizontal placement | Vertical placement |
| ------ | -------------------- | ------------------ |
| 右上     | Right                | Top                |
| 左上     | Left                 | Top                |
| 左下     | Left                 | Bottom             |
| 上中央    | Center               | Top                |
| 下中央    | Center               | Bottom             |
| 右下（標準） | Right                | Bottom             |

画面端からの距離の微調整や、サブモニターへの通知表示も可能です。

**対象の拡張機能：** [Customize Windows notifications placement](https://windhawk.net/mods/notifications-placement?utm_source=chatgpt.com)

なお、Windhawkは非公式のカスタマイズツールなので、Windowsアップデートによって動作に不具合が生じる場合があります。

標準機能だけで済ませたい場合は、通知の位置変更はできませんが、通知バナーを非表示にすることは可能です。
